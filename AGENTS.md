# Правила для ИИ-помощников (Claude, GPT/Codex)

Проект: браузерная онлайн-игра «СЕКТЫ» (бывший LAST EXIT). Владелец — Андрей. Общение — по-русски, коротко.

## Ветки и выкладка
- Push в `main` = автоматическая выкладка на https://last-exit.zacharov-andrej.workers.dev (Cloudflare Workers Builds).
- **GPT/Codex**: в `main` напрямую не пушит. Ветка `gpt/<задача>` → Pull Request с описанием по-русски (что сделано, как проверить). Сливает Андрей.
- **Claude**: по договорённости с Андреем коммитит в `main` сам после проверки.
- Перед началом работы — `git pull`. Одна задача — одна ветка/PR, маленькие изменения.
- Не переформатировать файлы целиком и не переименовывать чужие функции без нужды — иначе конфликты.

## Нельзя
- Писать секреты, токены, пароли в код, коммиты и чат.
- Менять протокол сервер↔клиент (бинарный снапшот, сообщения `{t:...}`) без согласования с Андреем.
- В `src/shared.js` ломать детерминизм генерации мира: никаких `rnd()` внутри `sort`, не менять порядок вызовов `rnd` без необходимости (иначе мир у сервера и клиентов разойдётся).
- Трогать другие проекты Андрея (ALEGERI / `zheltyi-kod`).

## Устройство
- `src/shared.js` — общее для сервера и клиента: генерация мира (seed), столкновения, лучи, оружие, секты, характеры жителей.
- `src/server.js` — Cloudflare Durable Object `World`: один город на всех, 20 тиков/с, жители и агенты сект, вербовка, службы, церкви.
- `src/client.js` — управление (ПК и телефон), HUD, сеть, предсказание движения.
- `src/render3d.js` — 3D на Three.js r128: изометрическая ортокамера, toon-стиль, контуры только у людей, инстансинг мира, здания, церкви, персонажи и анимация (`poseChar`, IK рук `reach`), эффекты.
- `src/index.html` — страница. `build.py` собирает всё в `worker.js`.

## Проверка перед коммитом/PR
1. `python3 build.py` — без ошибок.
2. `npx wrangler dev --port 8787` → открыть игру, выбрать секту, побегать, пострелять. В консоли браузера нет ошибок.
3. FPS (`#perf` в адресе) не упал. Основные игроки — с телефона.
4. Стили для сравнения графики: `#toonall`, `#bright`, `#real`.
